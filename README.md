# omok-room

서버 없이 링크만으로 둘이 쓰는 채팅 + 오목 사이트.

사이트: https://mnzujp-px.github.io/omok-room/

## 사용 방법

1. 링크를 열면 주소 끝에 방 코드(`#abc123`)가 붙고, 먼저 연 사람이 방장이 된다.
2. 위쪽 "링크 복사"로 주소를 복사해 친구에게 보낸다. 같은 링크를 열면 같은 방에 들어온다.
3. 이름을 정하면 채팅을 보낼 수 있다.

## 기능

### 채팅
- 실시간 채팅 (최근 200개 유지), 여러 명이 같이 사용 가능
- 마크다운 지원: 제목(1~6단계), 굵게, 기울임, 취소선, 코드, 코드 블록, 링크·자동 링크, 이미지, 목록(중첩·체크리스트), 인용, 표(정렬), 구분선, 줄바꿈. 자세한 사용법은 [MARKDOWN.md](MARKDOWN.md)
- 입력은 Enter로 보내기, Shift+Enter로 줄바꿈 (여러 줄 입력창)
- 상대 메시지는 ChatGPT 답변처럼 위에 "이름 · 시간" 줄과 구분선, 아래에 복사 아이콘을 표시
- 내 메시지는 말풍선, 상대 메시지는 글만 표시 (ChatGPT 스타일)
- 이름은 브라우저에 저장

### 오목 (캔버스 패널)
- 15x15 판, 흑·백 자리에 앉아서 번갈아 둠
- 방장이 규칙을 검증 (내 차례, 빈 칸, 승리 판정)
- 5목 이상 연결 시 승리 표시, "새로 시작"으로 초기화
- 흑돌은 검은 원, 백돌은 흰 원 (라이트·다크 모드와 상관없이 항상 같고 회색 테두리로 구분)
- 승리하면 모든 접속자 화면에 "흑돌 WIN!!" / "백돌 WIN!!" 모달이 뜨고 콘페티가 터짐 (닫기 / 새로 시작 버튼)
- 콘페티는 캔버스 투명도 설정을 따르고, 모션 줄이기 설정을 켠 사람에게는 나오지 않음
- 이미 끝난 판이 있는 방에 들어갈 때는 모달과 콘페티가 나오지 않음
- 채팅창에 `/승리` 또는 `/win`을 입력하면 내 화면에서만 승리 모달과 콘페티를 미리 볼 수 있음 (채팅으로 전송되지 않음)
- 앉지 않은 사람은 구경만 가능
- 승리 모달이 떠 있는 동안 모달 바깥을 클릭하면 클릭한 자리에서 콘페티가 터짐 (몇 번이든 가능)
- "AI와 대결": 혼자서 컴퓨터와 대결 (나는 흑, AI는 백). 내 브라우저에서만 진행되어 방과 친구 화면에는 영향 없음
  - AI는 점수 계산 방식의 간단한 프로그램 (자기 5목 우선, 상대 4목·열린 3목 차단, 중앙 선호). 난이도 조절은 아직 없음
  - 이기면 콘페티, AI가 이기면 모달만 표시. "AI 대결 끝내기"로 원래 판으로 복귀

### 알까기 (캔버스 패널)
- 판 위쪽 "오목 / 알까기" 스위치로 게임을 바꿈 (둘 다 앉아 있지 않거나 앉은 사람만 바꿀 수 있고, 알이 움직이는 중에는 불가). AI 대결은 오목에서만 가능
- 한 쪽 7개씩 놓고 시작, 내 차례에 내 알을 누른 채 반대 방향으로 끌었다 놓으면 튕김 (끌수록 세게, 최대 세기 제한)
- 끌고 있는 동안 방향과 세기를 점선으로 표시, 알끼리 부딪히면 밀려나고 판 밖으로 나간 알은 사라짐
- 알이 모두 멈추면 상대 차례, 상대 알이 모두 사라지면 승리 (WIN!! 모달과 콘페티는 오목과 동일)
- 물리 계산은 방장 브라우저가 하고 알 위치를 모두에게 계속 전송 (친구 화면에서도 같은 모습으로 보임)
- 흑·백 자리는 오목과 같은 자리를 사용

### 숫자 야구 · 지뢰찾기 · 가위바위보
- 판 위쪽 선택 상자에서 오목 / 알까기 / 숫자 야구 / 지뢰찾기 / 가위바위보를 고름. 흑·백 자리는 모든 게임에서 공통
- 숫자 야구: 각자 서로 다른 숫자 3개를 비밀로 정하고 번갈아 상대 숫자를 맞힘 (자리와 숫자가 맞으면 S, 숫자만 맞으면 B). 먼저 3S를 맞히면 승리, 끝나면 두 사람의 비밀 숫자 공개
- 지뢰찾기(협동): 9x9, 지뢰 10개를 모두가 같은 판에서 같이 풂. 앉지 않은 사람도 참여 가능. 왼쪽 클릭 열기, 오른쪽 클릭 깃발(또는 위쪽의 깃발 토글 스위치). 위쪽 가운데에 깃발 토글과 남은 지뢰 수(아이콘)가 한 줄로 표시되고 세로 스크롤 없이 한 화면에 들어감. 첫 클릭은 항상 안전하고, 전부 열면 "클리어!!" 모달과 콘페티
- 가위바위보: 두 사람이 동시에 고르고 둘 다 고르면 공개. 먼저 3번 이기면 승리. 상대가 무엇을 골랐는지는 공개 전까지 방장 브라우저에만 있어 화면에 나타나지 않음
- 숨겨야 하는 값(선택, 비밀 숫자, 지뢰 위치)은 방장 브라우저만 가지고 있음
- 판 위쪽의 규칙(i) 아이콘에 마우스를 올리면 지금 게임의 규칙이 말풍선으로 뜸. 게임 화면 안에는 규칙 설명 없이 게임 요소만 표시
- 숫자 야구 입력: 3칸 숫자 슬롯과 숫자 키패드(0~9, 지움, 확인). 이미 쓴 숫자는 비활성화되고 키보드 숫자·Backspace·Enter로도 입력 가능. 기록은 숫자 칸과 S/B 알약으로 표시
- 주사위 버튼으로 지금 게임을 뺀 나머지 중 하나를 무작위로 골라 줌 (결과는 토스트로 3초간 표시)
- 게임 선택과 주사위, AI 대결·새로 시작 버튼은 판 위쪽 줄에 고정되고, 상태 문구는 판 아래 한 줄에 표시되어 게임을 바꿔도 위치가 움직이지 않음
- 혼자 있거나 상대가 앉지 않은 상태에서 시도하면 "상대가 앉으면 시작할 수 있어요" 같은 토스트를 3초간 띄움

### 접속자 상태
- 왼쪽 맨 끝 아이콘 줄(ChatGPT 앱처럼)의 아래쪽에 접속자 프로필 표시: 원형 아바타(이름 첫 글자)와 오른쪽 아래 상태 점
- 활동 중이면 초록 채운 점, 자리 비움이거나 다른 창을 보고 있으면 속이 빈 회색 동그라미. 마우스를 올리면 이름과 상태 표시
- 방장은 아바타 안에 이름 첫 글자 대신 노란 왕관 아이콘이 들어감. 내 프로필(맨 아래)을 누르면 이름 변경, 상태 선택(대화 가능 / 업무 중 / 회의 중 / 자리 비움), 다크 모드, 문의 보내기 메뉴가 열림

### 문의
- 위쪽 "문의" 버튼으로 모달을 열어 분류(문의 / 게임 제안 / 기능 추가 / 응원 / 기타)를 고르고 한 줄 이상 작성
- 이름은 선택 입력, 비우면 채팅 이름 또는 "익명"으로 전송
- Web3Forms로 운영자 메일에 전달 (공개용 접수 키 사용, 허용 도메인 제한은 Web3Forms 설정에서 관리)
- 분류는 메일 번역 과정에서 글자가 바뀌지 않도록 내용 맨 앞에 "분류: ○○"로 포함
- 스팸 방지용 숨은 입력칸 포함, 모달이 열려 있을 때 Esc는 모달만 닫음

### 프로필 메뉴
- 왼쪽 아래 내 프로필을 누르면 메뉴가 열림: 이름 변경, 다크 모드 스위치, 문의 보내기
- 사이드바를 접거나 폭이 좁은 화면에서는 이름·다크 모드·문의 버튼이 위쪽 줄에 나타남

### 접속 표시
- 위쪽 줄에 "● N명 접속 중" (연결되면 초록 점, 끊기면 회색 점과 이유 안내)

### 화면
- ChatGPT 느낌의 3단 레이아웃 (사이드바 / 대화 / 캔버스), 사이드바 제목은 "ChatGPT" 글자만 표시
- 입력창은 높이 52px 알약 모양, 보내기 버튼은 지름 32px 파란 원
- 라이트·다크 모드 전환 스위치 (프로필 메뉴, 설정은 브라우저에 저장)
- 캔버스 열기·닫기 아이콘, 경계 막대를 끌어서 너비 조절 (더블클릭하면 기본값)
- 캔버스 패널 오른쪽 위, 흑·백 자리 줄 위의 얇은 슬라이더로 투명도 조절 (10~100%, 브라우저에 저장, 웨일 브라우저 스타일)
- 사이드바(ChatGPT 제목 옆)와 캔버스(패널 왼쪽 위)에 각각 접는 아이콘, 접으면 열기 아이콘이 채팅 위쪽 줄에 나타남 (상태는 브라우저에 저장)
- 채팅 스크롤바는 스크롤하는 동안만 표시
- 채팅 입력창은 클릭해도 포커스 테두리가 뜨지 않고, 입력 커서는 글자색으로 뚜렷하게 표시
- 폭이 좁은 화면에서는 사이드바가 접히고 캔버스는 아이콘으로 열기

### 숨기기
- Esc 키 또는 "숨기기" 버튼으로 스프레드시트 화면으로 전환, 다시 Esc 또는 클릭하면 복귀
- 탭 이름과 링크 미리보기 이름은 업무 문서 이름으로 표시

## 동작 방식과 한계

- 서버가 없고 PeerJS(WebRTC)로 브라우저끼리 직접 연결한다. 방장 브라우저가 대화·판·접속자 정보를 모두 가진다.
- 방장이 새로고침하거나 창을 닫으면 대화와 판이 사라지고 연결이 끊긴다.
- 손님이 새로고침하면 대화는 방장에게서 다시 받지만 오목 자리는 풀린다.
- 저장 기능은 아직 없다. 개선 후보: 방장 브라우저에 저장 후 복원, 자동 재연결, 또는 별도 저장소(Supabase 등).

## 기술

- 순수 HTML/CSS/JS 단일 파일 (`index.html`), 빌드 도구 없음
- PeerJS 1.5.4 (CDN), Pretendard 폰트 (CDN)
- 디자인 토큰: Plus X Vanilla 기반, 라운드는 ChatGPT에 맞춤
- 글꼴 Pretendard, 자간 -2.5%
- 문의 전달: Web3Forms
- 호스팅: GitHub Pages
