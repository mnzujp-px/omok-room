# omok-room

서버 없이 링크만으로 여럿이 쓰는 채팅 + 미니 게임 사이트.

사이트: https://mnzujp-px.github.io/omok-room/

## 사용 방법

1. 링크를 열면 주소 끝에 방 코드(`#abc123`)가 붙고, 먼저 연 사람이 방장이 된다.
2. 위쪽 "링크 복사"로 주소를 보내면 같은 방에 들어온다.
3. 이름을 정하고 채팅하거나, 흑·백 자리에 앉아 게임을 한다.

## 기능

### 채팅
- 실시간 채팅, 여러 명 사용 가능
- 마크다운 지원 ([MARKDOWN.md](MARKDOWN.md)), 서식 버튼, 크롬 내장 AI 또는 기본 규칙으로 말투 다듬기

### 게임
판 위쪽 선택 상자에서 고르고, 주사위 버튼으로 무작위 선택. i 아이콘에 마우스를 올리면 규칙이 보인다.

- 오목: 혼자 할 수 있는 AI 대결 포함
- 알까기: 알을 끌었다 놓아 튕기기
- 숫자 야구: 사이트가 정한 숫자를 번갈아 맞히기
- 지뢰찾기: 모두가 같이 푸는 협동 모드
- 가위바위보: 먼저 3번 이기면 승리

이기면 모달과 콘페티가 뜬다(프로필 메뉴의 "승리 효과"로 둘 다 끌 수 있음).

### 접속자
- 왼쪽 아이콘 줄에 접속자 프로필, 활동 상태 점, 방장 왕관 표시
- 내 프로필 메뉴에서 이름, 상태, 다크 모드, 승리 효과, 문의 설정

### 화면
- ChatGPT 느낌의 3단 레이아웃(아이콘 줄 / 사이드바 / 대화 / 캔버스)
- 라이트·다크 모드, 사이드바·캔버스 접기, 캔버스 너비와 투명도 조절

### 기타
- 문의 보내기(Web3Forms로 메일 전달)
- Esc 키로 스프레드시트 화면으로 전환
- 탭 이름과 링크 미리보기는 업무 문서 이름으로 표시

## 동작 방식과 한계

- 서버 없이 PeerJS(WebRTC)로 브라우저끼리 직접 연결하며, 방장 브라우저가 모든 상태를 가진다.
- 방장은 방 상태를 자기 브라우저에 저장해 새로고침 뒤 복원한다(같은 브라우저에서 24시간 안). 손님은 끊기면 자동으로 다시 연결된다.
- 방장이 창을 닫고 있는 동안은 대화가 오가지 않는다.
- 방장 없이 오래 보관하려면 별도 저장소(Supabase 등)가 필요하다.

## 기술

순수 HTML/CSS/JS 단일 파일(`index.html`), PeerJS 1.5.4, Pretendard, GitHub Pages 호스팅.
