# omok-room

서버 없이 링크만으로 둘이 쓰는 채팅 + 오목 사이트.

사이트: https://mnzujp-px.github.io/omok-room/

## 사용 방법

1. 링크를 열면 주소 끝에 방 코드(`#abc123`)가 붙고, 먼저 연 사람이 방장이 된다.
2. 위쪽 "링크 복사"로 주소를 복사해 친구에게 보낸다. 같은 링크를 열면 같은 방에 들어온다.
3. 이름을 정하면 채팅을 보낼 수 있다.

## 기능

### 채팅
- 실시간 채팅 (최근 200개 유지)
- 내 메시지는 말풍선, 상대 메시지는 글만 표시 (ChatGPT 스타일)
- 이름은 브라우저에 저장

### 오목 (캔버스 패널)
- 15x15 판, 흑·백 자리에 앉아서 번갈아 둠
- 방장이 규칙을 검증 (내 차례, 빈 칸, 승리 판정)
- 5목 이상 연결 시 승리 표시, "새로 시작"으로 초기화
- 앉지 않은 사람은 구경만 가능

### 접속자 상태
- 왼쪽 사이드바 맨 아래에 프로필 형태로 표시 (이름 첫 글자, 이름, 상태 점)
- 내 상태는 내 프로필에서 선택: 대화 가능 / 업무 중 / 회의 중 / 자리 비움
- 다른 창·탭을 보고 있으면 "대화 가능 · 다른 창 보는 중"처럼 상태 뒤에 자동으로 붙음

### 화면
- ChatGPT 느낌의 3단 레이아웃 (사이드바 / 대화 / 캔버스), 사이드바 제목은 "ChatGPT" 글자만 표시
- 라이트·다크 모드 전환 (설정은 브라우저에 저장)
- 캔버스 열기·닫기 아이콘, 경계 막대를 끌어서 너비 조절 (더블클릭하면 기본값)
- 캔버스 패널 오른쪽 위의 작은 슬라이더로 캔버스 투명도 조절 (10~100%, 브라우저에 저장)
- 폭이 좁은 화면에서는 사이드바가 접히고 캔버스는 아이콘으로 열기

### 숨기기
- Esc 키 또는 "숨기기" 버튼으로 스프레드시트 화면으로 전환, 다시 Esc 또는 클릭하면 복귀
- 탭 이름과 링크 미리보기 이름은 업무 문서 이름으로 표시

## 동작 방식과 한계

- 서버가 없고 PeerJS(WebRTC)로 브라우저끼리 직접 연결한다. 방장 브라우저가 대화·판·접속자 정보를 모두 가진다.
- 방장이 새로고침하거나 창을 닫으면 대화와 판이 사라지고 연결이 끊긴다.
- 손님이 새로고침하면 대화는 방장에게서 다시 받지만 오목 자리는 풀린다.
- 저장 기능은 아직 없다. 개선 후보: 방장 브라우저에 저장 후 복원, 자동 재연결, 또는 별도 저장소(Supabase 등).

## 기술

- 순수 HTML/CSS/JS 단일 파일 (`index.html`), 빌드 도구 없음
- PeerJS 1.5.4 (CDN), Pretendard 폰트 (CDN)
- 디자인 토큰: Plus X Vanilla 기반, 라운드는 ChatGPT에 맞춤
- 글꼴 Pretendard, 자간 -2.5%
- 호스팅: GitHub Pages
